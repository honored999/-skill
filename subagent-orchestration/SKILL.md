# Implementation ownership
Use the simplest ownership that completes the authorized task.
- Current agent handles clear localized source fixes, configuration, docs, Git coordination and already authorized execution. Smallness is a valid reason not to delegate.
- For substantial independent work or requested delegation, prepare a brief and copyable prompt; default to user manual dispatch. Automatic agents/chats require explicit authorization.
- Executor/model selection belongs to the user; do not prescribe a model/profile or block on unavailable labels.
- All workers are leaves: no nested agents/tasks/reviewers/fixers/validators. Keep one active owner per lane.
- Do not split an ordinary fix into separate implementer/fixer/validator chats. Continue in scope; use another context only for a real independence need or user request.

# Acceptance
Verify material HANDOFF claims against the final diff and existing evidence. Reuse unchanged accepted evidence; do not restart a whole validation/review pipeline at each stage. Small blocker fixes may be inspected directly; obtain independent review only for new or unresolved substantial risk.
Use manual-subagent-handoff only when actually delegating. Read level3-review only when independent review is warranted. A brief does not grant unavailable permissions; preserve user data and unrelated changes. Report actual completion/blockers concisely.
